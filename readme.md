# 📘 Lista de Exercícios 01 – FullStack +PraTi & CodificaEdu

Bem-vindo à **Lista de Exercícios 01** do curso de Desenvolvedor **FullStack** promovido pelo **+PraTi** em parceria com a **CodificaEdu**.  
Aqui você encontrará 15 exercícios básicos de lógica de programação usando **JavaScript com Node.js**. 🚀

---

## 📦 Requisitos

Antes de começar, certifique-se de ter os seguintes pré-requisitos instalados:

- 🟢 [Node.js](https://nodejs.org/) (versão **14 ou superior**, preferencialmente)
- 💻 Terminal com Git

---

## ⬇️ Clonando o projeto

Abra seu terminal e execute:

```bash
git clone https://github.com/talesgodinho/Lista-01-Codifica-Edu.git
cd Lista-01-Codifica-Edu
```

---

## 📁 Instalando as dependências

Com o terminal posicionado dentro da pasta do projeto:

```bash
npm install
```

---

## ▶️ Executando os exercícios

Os exercícios estão nomeados de forma sequencial, de `exercicio01.js` até `exercicio15.js`.

Para rodar um exercício, utilize o terminal da seguinte forma (estando na pasta do projeto):

```bash
node exercicio01.js
```

Troque o número conforme o exercício desejado:

```bash
node exercicio07.js
node exercicio12.js
...
```
